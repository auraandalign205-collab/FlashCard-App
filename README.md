# 📚 Flashcard App

A simple and interactive Flashcard App built using HTML, CSS, and JavaScript.

This project is designed to make learning and revision easier by allowing users to study information through digital flashcards.

## ✨ Features

- Interactive flashcards
- Simple and user-friendly interface
- Clean and responsive design
- Easy navigation between flashcards
- JavaScript-powered interactions
- Works directly in the web browser

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 Purpose

The main purpose of this project is to create a simple learning tool that helps users revise important information using interactive flashcards.

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start using the Flashcard App.
